## Featured Projects

### 01 — Restaurant Ordering System

A full-stack QR-based restaurant ordering system designed around the real restaurant workflow.

Customers can scan a table QR code, browse the digital menu, search and filter items, add items to a cart, place orders, and track their order status.

The system also includes:

- Kitchen Display System
- Real-time order updates
- Manager/Admin dashboard
- Menu management
- Order analytics
- QR-based table access
- MySQL database integration

**Technologies:** React · Vite · Node.js · Express.js · MySQL · Socket.IO

[View Project on GitHub](https://github.com/TnebebZewdu/restaurant-ordering-system)

## Run Locally

Clone the repository:

```bash
git clone https://github.com/TnebebZewdu/tnebeb-portfolio.git
```

Move into the project directory:

```bash
cd tnebeb-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
